仲間内年間麻雀ランキング大会 規約

制定・運用規約

第1条　大会の目的

本大会は、仲間内で麻雀を楽しみながら、年間を通じた成績をメダルで管理し、毎年12月に開催する決勝戦によって年間チャンピオンを決定することを目的とする。

第2条　参加資格

  1. 麻雀が好きであること。
  2. 大会専用のLINEグループに参加していること。
  3. 大会への参加意思を表明していること。

第3条　年間スケジュール

  1. 年間ランキングの対象期間は、毎年1月1日から11月30日までとする。
  2. 12月は年間ランキングの集計対象外とし、メダルの増減は行わない。
  3. 毎年12月に年間ランキング上位3名による決勝戦を開催する。
  4. 決勝戦当日は、決勝進出者以外のメンバーも、都合が合えば自由に麻雀を楽しむことができる。
  5. 12月の自由対局についてもメダルの増減は行わない。

第4条　メダルの初期設定

  1. 毎年1月の大会開始時に、参加者全員がメダル30枚を保有した状態でスタートする。
  2. メダルは毎年リセットし、前年からの持ち越しは行わない。
  3. メダルの保有枚数によって年間ランキングを決定する。

第5条　通常対局のルール

  1. 決勝戦以外の麻雀については、人数、ルール、点数計算、開催形式などは自由とする。
  2. メダルの授受については、以下の共通ルールを適用する。
  3. その日の対局参加者のうち、最も順位が高かった者が、最も順位が低かった者からメダル1枚を受け取る。
  4. 4人打ちの場合、2位・3位はメダルの増減なしとする。
  5. 3人打ちの場合、2位はメダルの増減なしとする。
  6. メダルの移動は1日につき合計1枚とする。
  7. 12月の対局は、決勝戦・自由対局を問わずメダルの増減を行わない。

第6条　対局回数のカウントと決勝参加資格

  1. 1日麻雀を開催した場合、対局回数を1回とカウントする。
  2. 同じ日に複数回対局しても、対局回数は1回とする。
  3. 仲間内のメンバーが2名以上参加している麻雀を対象対局とする。
  4. 決勝戦への参加資格は、1月から11月までに対象対局に12回以上参加していることとする。

第7条　年間ランキング

  1. 年間ランキングは、11月30日時点のメダル保有枚数によって決定する。
  2. メダル保有枚数が同じ場合は、年間の対象対局参加回数が多い者を上位とする。
  3. 第6条の決勝参加資格を満たした者のうち、年間ランキング上位3名が決勝戦に進出する。
  4. 年間ランキングは11月30日をもって確定し、12月の対局結果による順位変更は行わない。

第8条　決勝戦

  1. 決勝戦は毎年12月に開催する。
  2. 決勝戦は年間ランキング上位3名で行う。
  3. 3名による3人打ち麻雀を行い、その結果によって年間最終順位を決定する。
  4. 決勝戦の1位を年間チャンピオン、2位を準優勝、3位を第3位とする。
  5. 決勝戦ではメダルの増減は行わない。

第9条　決勝戦当日の自由対局

  1. 決勝進出者以外のメンバーも、都合が合えば参加できる。
  2. 決勝戦と並行して、自由に麻雀を楽しむことができる。
  3. 自由対局ではメダルの増減を行わない。
  4. 自由対局への参加は任意とする。

第10条　運営・記録

  1. 対局結果およびメダルの増減は、LINEグループ等で共有・記録する。
  2. 年間ランキングは11月30日時点のメダル保有枚数に基づいて管理する。
  3. 規約に定めのない事項や解釈に疑義が生じた場合は、参加者間で協議して決定する。

第11条　倫理規定・参加者の心得

本大会は、仲間内で麻雀を健全に楽しむことを目的とし、参加者全員が以下の規定を遵守するものとする。

  1. 不正行為の禁止イカサマ、インチキ、その他大会の公平性を損なう不正行為を一切禁止する。不正行為を行った者は、その年の年間ランキングの対象外とし、悪質な場合は大会から除名する。
  2. 秘密保持メンバー外の者に対して、対局における勝ち負け、個人の成績、金銭の授受等について口外しないこと。ただし、参加者を募る目的で、本会の存在や活動について紹介することは認める。
  3. 金銭等の授受に関する節度社会通念から過度に逸脱した金銭その他の授受は厳に慎むこと。法令を遵守し、常識と節度を持って娯楽の範囲を逸脱しないこと。
  4. 健全な娯楽としての参加麻雀はあくまで娯楽として楽しむものとし、仕事、家庭、日常生活に支障をきたさない範囲で参加すること。
  5. 相互尊重参加者同士が互いを尊重し、節度ある言動を心掛けること。勝敗にかかわらず、楽しく気持ちよく麻雀ができる環境を維持すること。
  6. 規定違反への対応倫理規定に違反した場合は、参加者間で事実関係を確認し、違反の程度に応じて警告、年間ランキング対象外、除名等の措置を講じることができる。

第12条　幹事・運営体制

  1. 本大会の会長は臼井さんとする。
  2. 会長は大会全体の運営を統括する。
  3. 11月30日時点の年間メダルランキング下位2名が、翌12月の決勝戦に向けた幹事役を担当する。
  4. 幹事役は、決勝戦の開催日程および開催場所を調整する。
  5. 幹事役は、決定した日程・場所等をLINEグループ内で参加者に案内する。
  6. 幹事役の担当範囲は、日程・場所の調整およびLINEグループへの案内までとする。
  7. 幹事役は、決勝進出者を含む全参加者の年間ランキングを対象として選出する。

第13条　連絡方法

  1. 大会に関する連絡、対局結果の報告、メダルランキングの共有、決勝戦の案内等は、原則として大会専用のLINEグループを通じて行う。
  2. 参加者はLINEグループでの連絡事項を確認し、円滑な大会運営に協力するものとする。

第14条　年間チャンピオン

決勝戦の最終順位1位の者を、その年の年間麻雀チャンピオンとする。
